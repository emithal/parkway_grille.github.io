Website Update Instructions

Simple steps to update menus and photos on the live website.

Important: After you save changes in GitHub, the website updates automatically in about 1-3 minutes.

Change Password

Use this if you want a new login password. The page will create the replacement file text for you.

3. Open Password File
  1. Type the new password twice.
  2. Click Generate New Password File.
  3. Click Copy New Password File.
  4. Click Open Password File.
  5. In GitHub, delete everything in the file and paste the copied text.
  6. Click Commit changes. The new password works after 1-3 minutes.

Step-by-Step

Direct links:

Open Image Folder

Open Menu PDF Folder

  1. Open this link in your browser:
    github.com/emithal/parkway_grille.github.io
  2. To update menu PDFs, open folder: files
    Examples: Dinner Menu.pdf, Lunch Menu.pdf, Brunch Menu.pdf
  3. To update website photos, open folder: images
  4. Click Add file then click Upload files
  5. Drag your new file into the upload box
    Use the same filename if replacing an old file.
  6. In the message box, type a short note
    Example: Update Dinner menu PDF
  7. Keep selected: Commit directly to the master branch
  8. Click the green button: Commit changes

Picture Guide

If Something Goes Wrong

  • If a PDF does not update, wait 3 minutes and refresh the website.
  • If you uploaded wrong file, upload the correct file with the same filename and commit again.
  • If you are unsure, stop and contact me before committing.

Permissions Needed

  • Your client must be a collaborator on this GitHub repo: emithal/parkway_grille.github.io.
  • Give them Write access (Read access is not enough to upload or commit).
  • GitHub Pages must stay set to publish from the master branch.
